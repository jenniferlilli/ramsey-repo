## Computational Investigations in Random Ramsey Theory: Clique Counts, Probability Crossings, and SAT-Verificed Colorings

Used to assist the paper [Random Ramsey](Random_Ramsey_SAT_Extension.docx), this code counts monochromatic K_3, K_4, and K_5 graphs in a randomly generated K_n graph for varying values of n and calculates the estimated probability that a monochromatic graph of the three types occurs in a given K_n graph while also backtesting using SAT to verify the estimated values are realistic, plotting the data for each of the data points specified.
